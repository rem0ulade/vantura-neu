Features — wie Grace wirklich arbeitet

Jeder Block erklärt Nutzen und Ablauf. Grün = im Produkt. Blau = als Nächstes auf der Roadmap.

Im Produkt

Multi-Agent Chat

Ein Composer für viele Coding-Agenten. Du wählst Agent und Modell — oder lässt Auto den passenden wählen.

Ein Thread, klare Führung

Claude, Codex, Cursor, Hermes, OpenClaw, Vibe und mehr in einem Workspace. Statuspunkte zeigen laufend / wartend / fertig.

Stop & Kontrolle

Laufende Turns gezielt stoppen. Composer-Entwürfe bleiben am Chat hängen.

@Mentions & Staffel

Agenten im Composer ansprechen. Übergabe Specs → Implementierung im gleichen Chat.

Desktop & iOS

Gleicher Stand über LAN oder Tailscale. Push, wenn etwas fertig ist oder auf dich wartet.

Im Produkt

Visuelle Pipelines

Wiederverwendbare Agenten-Ketten — mit React-Flow-Canvas, NL-Vorschlag und gespeicherten Läufen.

Canvas-Builder

Start → Agent → End auf einem visuellen Graphen. Speichern und starten ohne Definition zu verlieren.

NL → Pipeline

Ablauf in Alltagssprache beschreiben; Grace schlägt eine Kette vor, die du vor dem Start prüfst.

Platzhalter

{input} startet den Lauf. {prev} reicht das vorherige Ergebnis weiter.

Anhänge pro Schritt

Dateien können mit einzelnen Pipeline-Schritten mitlaufen.

Im Produkt

Live Activity

Alle laufenden Turns und Pipelines ohne Chat-Hopping — Timeline, Freigaben, Kennzahlen.

Timeline

Parallele Agenten bleiben sichtbar. Detailpanel mit Status, Modell, Tools, Dateien und Kosten.

Stop & Pause

Turn beenden oder Pipeline pausieren — Deep-Link zurück in den Chat.

Approval-Queue

Tool- und Plan-Freigaben an einer Stelle, statt versteckt in Threads.

Kennzahlen

Aktiv, Freigaben, Tool-Aufrufe, Dateien, geschätzte API-Kosten — inkl. Statusleisten-Badges.

Im Produkt

Decision Log

Architektur- und Produktentscheidungen mit Begründung — browsen, korrigieren, exportieren.

Manuell + Review

Selbst eintragen oder Auto-Vorschläge aus abgeschlossenen Turns prüfen (opt-in).

Verlinkter Kontext

Jeder Eintrag kann auf Chat/Run und betroffene Dateien zeigen.

Export

Gefilterte DECISIONS.md fürs Projekthandbuch herunterladen.

Bleibt bei dir

In deiner lokalen Grace-Datenbank — kein SaaS-Wiki.

Im Produkt

Shared Memory & Projekt-Kontext

Projektnotizen, die in neue Chats injiziert werden — Agenten starten orientiert.

Annehmen / Verwerfen

Vorschläge aus Runs werden zu dauerhaftem Projektgedächtnis — du bleibst Editor.

Prefix, kein Prompt-Spam

Kontext landet dort, wo die Plattform ohnehin injiziert — unabhängig vom Agenten.

Im Produkt

Kanban

Team-Board neben dem Chat: Spalten, Karten, Session-Links — Desktop und iOS.

Board parallel zum Chat

Status von Triage bis Done. Karten verknüpfen Chats; Deep-Links springen zur Aufgabe.

Live ohne Flackern

Hintergrund-Poll aktualisiert nur bei echten Änderungen.

Auto-Cards (opt-in)

Im Team-Chat kann ein Label eine Karte anlegen und zuweisen.

Benachrichtigungen

Übergänge nach erledigt oder blockiert lösen Push/Slack aus.

Im Produkt

Broadcast & Best-of-N

Eine Nachricht an mehrere Agenten — Antworten live vergleichen, optional einen Schiedsrichter wählen.

Parallel denken lassen

Ideal für Architekturfragen: mehrere Modelle, eine Vergleichsansicht.

Best-of-N

Ein Agent kürt die beste Antwort oder fasst zusammen — du wählst den Richter.

Im Produkt

Worktree, Diff & Dateien

Transparenz für autonome Agenten: Dateien, Diffs, was wirklich passiert ist.

Git-Worktrees

Isolierte Arbeitskopien pro Experiment. Jede Worktree kann als Projekt erscheinen.

Diff & Ship-it

Änderungen sehen, committen, optional pushen und PR öffnen.

Drag & Drop

Dateien aus dem Worktree-Panel in den Composer ziehen.

Im Produkt

Coding Modus & Magic Text

Zwei Hebel für klarere, günstigere Interaktion — ohne Agenten zu tauschen.

Coding Modus

Optional: sparsame Output-Regeln. Weniger Essay, mehr Ergebnis. Default aus.

Magic Text

Rohtext in Code-Request, Mail, Team-Aufgabe oder Notiz wandeln — ein Klick.

Im Produkt

Desktop App & iOS Companion

Grace läuft als Desktop-App um den lokalen Server. Das iPhone dockt an denselben Workspace an.

Desktop

Native Shell, Tray, Dateidialoge, Server-Steuerung, Links im Systembrowser.

iOS

Chats, Kanban, Composer, Push. LAN oder Tailscale — ohne Cloud-Zwang für Inhalte.

Im Produkt

Kosten, Privacy & Kontrolle

Self-hosted heißt nicht ohne Governance — sondern Governance bei dir.

Auto- / Streng-Modus

Volle Autonomie oder Freigaben bei sensiblen Aktionen.

Kosten & Usage

Geschätzte API-Kosten und Provider-Usage — klar beschriftet, keine Abo-Rechnung.

Privacy-Indikatoren

Sichtbar, ob ein Turn lokal bleibt oder über eine externe CLI geht.

Geräte & Restore

Geräteverwaltung und Session-Restore — der Workspace bleibt dein Haus.

Im Produkt

Grace Local

Private lokale Modelle mit Grace-Identität — nutzbar ohne Claude-, Codex- oder andere KI-Abos für den Local-Pfad.

Stufen

Nano (leicht, z. B. Phi-Klasse) · Core · Code · stärkere Stufen bei guter Hardware.

First Run

Hardware-bewusste Einrichtung mit lokaler Runtime (z. B. Ollama).

Gleiche Oberfläche

Local sitzt neben Claude, Codex, Cursor im selben Composer und in Pipelines.

Privacy-USP

Install → lokales Modell → Grace-Systemprompt → erster Prompt. Kein API-Key für Local nötig.
