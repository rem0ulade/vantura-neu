Privat als Default

Dein Mac ist der Server. Chat-Inhalte speichert Vantura nicht zentral. Verbundene Agenten (BYOK) können eigene Provider nutzen — Grace macht den Datenweg sichtbar. Details: Datenschutzerklärung.

Self-hosted first

Grace.app installieren. Daten, Keys und Projekte bleiben auf deinem Rechner — keine verpflichtende Vantura-Chat-Cloud.

Grace Local

Open-Source-Modelle lokal für Offline- oder sensible Arbeit — Nano (Phi-Klasse) und stärkere Stufen.

Klarer Datenweg

Privacy-Indikatoren zeigen, ob ein Turn lokal bleibt oder über eine externe CLI/API geht.

Du gibst frei

Streng-Modus, Tool-Freigaben und Live Activity halten Autonomie unter Kontrolle.

Enterprise-Option

On-Prem, private EU-Cloud oder Hybrid. Lokaler Betrieb hilft — Governance hängt an eurer Konfiguration.

So startet Grace

Endprodukt, kein Terminal-Ritual. Doppelklick, lokal, unter deiner Kontrolle.

Installieren

Agenten verbinden

Führen

Auto- oder Streng-Modus, Budget, Geräte, Stop pro Turn. Grace orchestriert — du entscheidest.
