Mac

Get the desktop workspace running smoothly.

Launch

Grace won’t start

Check macOS Gatekeeper. Open System Settings → Privacy & Security and allow Grace once after the first blocked launch.

Performance

Grace feels slow

Close inactive chats, inspect local model load and provider limits, then use stricter execution settings for demanding workflows.

Agents

A connector is missing

Confirm that the corresponding CLI is installed and available on your Mac. Restart Grace so discovery can run again.

Local

Local model unavailable

Check that the local runtime is running, the selected model is installed and enough memory is available for the chosen tier.

iOS Companion

Your workspace from the phone, without moving it to the cloud.

TestFlight

Install and update

The companion is distributed through TestFlight during early access. Keep the newest available build installed.

Connection

Connect to your Mac

Use the same LAN or Tailscale network, keep Grace running on the Mac and select the available workspace in the app.

Notifications

Push stays silent

Check Grace notification permissions in iOS Settings and confirm that the Mac workspace can reach the companion.

Remote access

Outside your home network

Use Tailscale for a private connection between your iPhone and Mac without exposing the Grace server publicly.

Workspace & data

Your projects stay local. Treat them like important work.

Backup

Back up Grace

Use Time Machine or a manual backup routine for the Grace workspace and project folders containing chats, runs and local state.

Privacy

Understand data paths

Local work stays on your Mac. External agents and providers may process the prompts you send to them; Grace makes that distinction visible.

Restore

Move to another Mac

Restore the workspace data and reconnect the installed agents. Provider authentication may need to be completed again.

Control

A run is stuck

Open Live Activity, stop or pause the turn, inspect pending approvals and restart only the affected step where possible.

Still blocked? Talk to a human.

Send the device, Grace version, affected agent and a short description of what happened. Screenshots help.
